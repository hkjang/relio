Air-Gapped Deployment Guide

Deploy quickly in offline environments using a single Docker image

🐳 Single Docker Execution

Import the single .tar.gz package from GitHub Release into your offline network.

gunzip -c relio-v1.0.0.tar.gz | docker load

# Run with 3 environment variables
docker run -d --name relio \
  -p 8080:8080 \
  -e POSTGRES_DSN="postgres://relio:pass@postgres:5432/relio" \
  -e BOOTSTRAP_ADMIN="admin" \
  -e BOOTSTRAP_ADMIN_PASSWORD="StrongAdminPassword123!" \
  -v relio-data:/var/lib/relio \
  relio:v1.0.0

⚙️ 3 Required Environment Variables

Relio requires only three environment variables to boot.

POSTGRES_DSN=postgres://relio:pass@localhost:5432/relio
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
