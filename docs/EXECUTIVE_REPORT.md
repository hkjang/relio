## 2. 해결하고자 한 핵심 과제 (Problem Statement)

1. **외산 CRM SaaS 라이선스 수수료 가중 및 Lock-in 해소**:
   - 영업 조직 확장 및 임직원 수 증가에 따라 매년 기하급수적으로 높아지는 Salesforce 등 외산 CRM SaaS 수수료 부담을 극복하고, 사내 영업 자산의 외부 기술 종속을 원천 차단.
2. **사내 B2B 영업 기밀의 외부 이탈 방지 및 100% 폐쇄망 배포**:
   - B2B 거래 단가, 영업 파이프라인, 고객사 담당자 정보가 외부 클라우드 서버에 저장되는 위험을 완벽히 차단하고, 외부 인터넷 통신이 전면 불가능한 사내 폐쇄망 인프라에 단일 컨테이너로 설치 운영.
3. **AI 에이전트 연동 시 보안 통제권 확보**:
   - Cursor, Claude Desktop 등 사내 AI Agent에 직접적인 DB SQL 접근 권한을 부여하지 않고, 호출자의 Function Permission과 Data Scope 교집합 내에서 안전하게 영업 지표를 조회하고 업무를 지원하는 체계 마련.

## 5. 아키텍처 및 보안 컴플라이언스 (Architecture & Security)

### 5.1 3대 환경변수 부트스트랩
Relio 애플리케이션 컨테이너는 최소 3개의 환경변수만으로 안전하게 부트스트랩됩니다.

```bash
POSTGRES_DSN=postgres://relio:Secr3tPass@10.10.50.5:5432/relio?sslmode=disable
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretAdminPassword123!
```

### 5.2 보안 및 데이터 보호 체계
- **Instance Master Key**: `/var/lib/relio` 볼륨 내 마스터 키를 이용한 AES-256-GCM 암호화 보관.
- **HMAC Key Digest**: Personal API Key 원문을 저장하지 않고 HMAC Digest 상태로 관리하며 7일 유예기간 키 회전(Rotation) 지원.
- **감사 로그 (Audit Trail)**: 모든 OIDC 설정 변경, 파이프라인 stage 수정, 승인 정책 변경 이력을 무결성 레코드로 기록.
