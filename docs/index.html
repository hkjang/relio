B2B CRM & 영업관리 플랫폼

사람을 위한 CRM, 시스템을 위한 API, AI Agent를 위한 MCP를 단일 패키지로

Relio는 외부 통신이 차단된 사내 폐쇄망 인프라에서 Customer 360 통합 뷰, 영업 파이프라인(Deal Health), Forecast 분석, Keycloak OIDC SSO 및 AI 에이전트를 위한 Streamable HTTP MCP를 단일 Docker 컨테이너로 제공하는 엔터프라이즈 B2B CRM입니다.

주요 기능

영업 기회 관리부터 예측, 계정 보안 및 AI 연동까지 지원합니다

🔍

Customer 360 & 중복 탐지

고객사 종합 정보, 거래 이력, 활동 기록을 한눈에 파악하며 중복 고객 자동 탐지 및 안전 병합을 지원합니다.

📈

Deal Health & Pipeline

영업 기회의 건강도(Deal Health)를 실시간 점수화하고 스테이지별 파이프라인 및 매출 Forecast 흐름을 분석합니다.

🏛️

3개 구역 분리 (/app, /me, /admin)

영업 파이프라인(`/app`), 개인화 대시보드(`/me`), 시스템·보안·감사 관리자 콘솔(`/admin`)을 명확히 분리 관리합니다.

🔐

Keycloak OIDC & Break Glass

Keycloak OIDC (PKCE) 인증과 네트워크 단선 상황을 대비한 삭제 불가능한 Break Glass 부트스트랩 계정을 결합했습니다.

🤖

Streamable HTTP MCP Server

Claude Desktop, Cursor 등 AI 에이전트가 호출자의 Function Permission 및 Data Scope 교집합 내에서 안전하게 지표를 검색합니다.

📦

오프라인 단일 Docker

Go API와 React SPA 자산이 통합된 단일 non-root Docker 이미지로 CDN이나 외부 폰트 다운로드 없는 100% 폐쇄망 배포를 보장합니다.

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

gunzip -c relio-v1.6.0.tar.gz | docker load

# 3개 필수 환경변수 및 1개 선택 환경변수로 구동
docker run -d --name relio \
  -p 8080:8080 \
  -e POSTGRES_DSN="postgres://relio:pass@postgres:5432/relio" \
  -e BOOTSTRAP_ADMIN="admin" \
  -e BOOTSTRAP_ADMIN_PASSWORD="StrongAdminPassword123!" \
  -e ENCRYPTION_KEY="$ENCRYPTION_KEY" \
  -v relio-data:/var/lib/relio \
  relio:v1.6.0

⚙️ 3대 필수 환경변수

Relio가 사용하는 필수 환경변수는 단 3개입니다.

POSTGRES_DSN=postgres://relio:pass@localhost:5432/relio
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!

자주 묻는 질문 (FAQ)

네. 외부 CDN, 폰트, 텔레메트리 다운로드가 전혀 없으며, Go 백엔드와 React 프론트엔드가 단일 Docker 이미지로 패키징되어 폐쇄망에서 완전 독립 동작합니다.

네. Relio는 /mcp Streamable HTTP 어댑터를 통해 호출자의 Function Permission 및 Data Scope 교집합 내에서 안전하게 영업 지표를 조회하고 제어합니다.

원문 키는 DB에 저장되지 않으며 HMAC Digest만 저장됩니다. 사용자는 7일간의 무중단 유예기간(Grace Period)을 갖는 원자적 키 회전(Rotation)을 실행할 수 있습니다.
