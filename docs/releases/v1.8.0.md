## Relio v1.8.0 — 마우스 없이도, 내 업무 공간

Relio v1.8.0은 두 가지 공백을 메웁니다. 키보드만으로는 어떤 레코드도 열 수 없었던 접근성 결함, 그리고 메뉴에는 있지만 실제 화면이 없던 개인 업무 영역입니다.

## 1. 키보드 접근성

목록의 행은 `<tr onClick>`이었습니다. Tab으로 도달할 수 없고 Enter로 열 수도 없었으므로, 마우스를 쓸 수 없는 사용자는 고객이나 요청을 **하나도 열 수 없었습니다.** 화면 낭독기에도 클릭 가능한 요소로 알려지지 않았습니다.

- 모든 클릭 가능한 행에 `tabIndex`, `role="button"`, 접근성 이름을 부여하고 Enter·Space로 열립니다. Space는 기본 스크롤 동작을 막아 사용자가 위치를 잃지 않게 합니다.
- 모달과 Drawer가 이제 실제 대화상자입니다. 열면 내부로 포커스가 이동하고, Tab이 안에 머물며, Escape로 닫히고, 닫으면 **원래 누른 위치로 포커스가 돌아옵니다.**
- 키보드 포커스 표시(`:focus-visible`)를 추가했습니다. 행이 Tab 대상이 된 만큼 어디에 있는지 보여야 합니다.

Playwright로 실제 키보드 입력을 시뮬레이션해 검증합니다: 행 도달 → Enter로 열기 → Escape로 닫기 → 포커스 복귀, 그리고 모달에서 Tab을 40회 눌러도 포커스가 빠져나가지 않는 것까지 19개 항목.

## 2. 개인 업무 공간 — 메뉴만 있던 6개 화면

내 현황, 내 영업목표, 내 일정, 내 알림, 저장된 검색, 즐겨찾기는 모두 안내문만 띄우는 자리표시자였습니다. 여섯 화면을 실제로 구현했습니다.

### 저장된 검색

자주 쓰는 필터 조합을 이름 붙여 보관합니다. 고객·고객의 목소리 화면에서 조건을 지정한 뒤 바로 저장하고, 칩을 눌러 되돌립니다.

저장되는 것은 **화면에 보이던 그 querystring**이며 서버는 이를 불투명한 문자열로 취급합니다. 적용 시 평소의 목록 API로 그대로 재생되므로, 저장된 검색이 소유자의 조회 범위를 넓히는 일은 구조적으로 불가능합니다. 같은 이름으로 다시 저장하면 갱신되므로 필터를 다듬어 같은 이름으로 덮어쓸 수 있습니다.

### 즐겨찾기

고객·영업기회·고객 요청·계약에 별표를 답니다. 즐겨찾기는 포인터만 저장하고 표시할 때마다 Data Scope가 적용된 조회로 다시 읽습니다. 따라서 담당 범위를 벗어난 레코드는 정리 작업 없이 자동으로 사라지며, 조회 권한이 없는 레코드는 별표조차 달 수 없습니다. 그렇지 않으면 즐겨찾기 목록이 범위 밖 데이터의 존재를 알려주게 됩니다.

### 내 현황 · 내 일정 · 내 알림 · 내 영업목표

- **내 현황**: 담당 범위 실적과 오늘 처리할 일, 수주율·평균 영업기간 지표
- **내 일정**: 다음 행동을 날짜별로 묶어 오늘·지난 일정을 구분해 표시
- **내 알림**: 전체 목록, 개별·일괄 읽음 처리
- **내 영업목표**: 기간별 목표와 달성률 막대

## 발견 및 수정한 오류

- 목록 행이 키보드로 도달·활성화 불가능해 마우스 없이는 레코드를 열 수 없던 문제
- 모달·Drawer가 포커스를 가두지 않아 Tab으로 뒤쪽 페이지로 빠져나가던 문제
- 대화상자를 닫아도 포커스가 원래 위치로 돌아오지 않던 문제
- 내비게이션이 실제 화면 없는 6개 항목을 노출한 문제
- `activityIcon`이 두 곳에 중복 정의된 문제
- 오프라인 스모크 테스트가 자체 요청량으로 API 요청 한도를 초과해 중단된 문제. 테스트가 명시적으로 한도를 해제하도록 바꾸고, 한도 로직은 단위 테스트로 별도 보장

## 검증 범위

- Go Test/Vet/`gofmt`, TypeScript Typecheck, React Production Build, 환경변수·정적자산 계약
- 요청 한도·로그인 시도 제한 단위 테스트(식별자별 독립성, 윈도 초기화, 성공 시 해제)
- 개인 작업공간 단위 테스트(리소스 화이트리스트, SQL에 삽입되는 식별자 안전성, 조직 NULL 처리)
- Playwright 키보드 검증 19항목 및 26개 화면 DOM 감사
- 오프라인 스모크 테스트에 저장된 검색 갱신·삭제, 즐겨찾기 토글, 범위 밖 레코드 별표 거부, 오늘 할 일·위험도 응답 검증 추가
- 실제 컨테이너에서 스모크 + 자격증명 연속성(교체·이관·Volume 삭제·잘못된 키) 전체 통과

## 업그레이드

마이그레이션 009가 자동 적용됩니다. 추가 권한 설정은 필요하지 않습니다. 저장된 검색과 즐겨찾기는 사용자 개인 데이터이며 별도 권한 없이 동작합니다.
