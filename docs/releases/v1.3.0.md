## Relio v1.3.0 — Admin Operations & UX

Relio v1.3.0은 관리 콘솔을 단순 설정 목록에서 **운영 판단과 즉시 조치가 가능한 Command Center**로 고도화한 Release입니다. 기존 CRM 업무 화면, 개인화 화면, 관리자 화면의 분리는 유지하면서 관리자 정보구조·운영 진단·감사 추적·모바일 사용성을 집중 개선했습니다.

## 주요 변경 사항

### 운영 Command Center

- 필수 운영 항목을 기반으로 0~100 **Operational Readiness Score**를 계산합니다.
- PostgreSQL, Schema Migration, Instance Master Key, Persistent Volume, Service URL, 사용자·조직, RBAC, Pipeline, Background Job을 필수 진단합니다.
- Keycloak OIDC, REST API, MCP, 승인 Workflow는 활성화 정책을 반영해 `HEALTHY`, `WARNING`, `CRITICAL`, `DISABLED`로 구분합니다.
- 의도적으로 비활성화한 OIDC나 승인 Workflow는 장애나 준비도 감점으로 처리하지 않습니다.
- 조치가 필요한 항목은 Action Center에서 우선순위와 설명을 확인하고 해당 설정으로 바로 이동할 수 있습니다.
- 활성 사용자, Personal Key, 최근 24시간 Audit, 진행 Opportunity를 운영 지표로 제공합니다.

### Diagnostics · Job Center

- 전체 진단 결과와 필수 여부를 별도 화면에서 확인할 수 있습니다.
- Application Version, Git Commit, Build Date, PostgreSQL Version, DB 크기, Schema Version과 마지막 Migration을 함께 표시합니다.
- Background Job의 READY/RUNNING/FAILED 수와 최근 작업, 시도 횟수, 오류를 확인할 수 있습니다.
- 3개 환경변수, 단일 Docker Image, Runtime Download 0개라는 Offline Runtime Contract를 관리 화면에서 확인할 수 있습니다.

### 안전한 Support Bundle

- 관리자가 운영 진단 정보를 JSON Support Bundle로 내려받을 수 있습니다.
- Password, Token, Personal Key, PostgreSQL DSN, OIDC Client Secret은 포함하지 않습니다.
- 오류 문자열에 포함될 수 있는 Password, Token, PostgreSQL Credential도 자동 마스킹합니다.
- Support Bundle 다운로드 작업은 `SUPPORT_BUNDLE_EXPORT` Audit으로 기록됩니다.

### 관리자 탐색과 반응형 UX

- 관리자 메뉴를 `운영`, `기본 설정`, `조직 · 권한`, `영업 정책`, `개발자`, `데이터`로 재구성했습니다.
- 관리자 전용 메뉴 검색과 `Ctrl/Command + K` 단축키를 제공합니다.
- 모바일에서 일부 관리자 메뉴가 숨겨지던 문제를 제거하고 전체 메뉴 Drawer를 제공합니다.
- Escape 닫기, 명확한 Focus Ring, Dialog Label, 메뉴 열림 상태 등 키보드·보조기기 접근성을 개선했습니다.
- 관리 화면의 지나치게 작은 본문·표·도움말 글자와 상태 대비를 보정했습니다.
- Desktop, Tablet, Mobile에서 Command Center, Diagnostics, 설정 Form과 Audit 상세가 자연스럽게 재배치됩니다.

### 설정·Audit UX

- 시스템 설정에서 변경 감지, 저장 중 상태, 저장 완료 시각과 중복 저장 방지를 제공합니다.
- Audit Log에서 Actor, Action, Resource, Request ID 통합 검색과 Channel 필터를 제공합니다.
- Audit 상세 Dialog에서 Actor, Channel, IP, Request ID와 변경 전/후 JSON을 비교할 수 있습니다.

### API

- `GET /api/v1/admin/operations` 응답을 준비도, Feature 상태, 진단, 조치 항목, 운영 Count, 최근 Job으로 확장했습니다.
- `GET /api/v1/admin/operations/support-bundle`을 추가했습니다.
- `GET /api/v1/admin/audit`에 `q`, `channel`, `action`, `resource`, `limit` 필터를 제공합니다.
- 내장 OpenAPI 문서에 새로운 관리자 운영 API를 반영했습니다.

## 보안 및 호환성

- 관리자 운영 API는 기존 `admin:read` 또는 Bootstrap Admin 권한을 그대로 적용합니다.
- Support Bundle은 Secret 원문과 환경변수 값을 읽거나 반환하지 않습니다.
- Bootstrap Admin, Keycloak OIDC, Personal Key Rotation, REST/MCP Permission 및 Data Scope 정책은 기존과 호환됩니다.
- Database Schema 변경이 없어 v1.2.0 Database를 그대로 사용하며 Docker Image 교체만으로 업그레이드할 수 있습니다.
- Keycloak 장애는 Relio 전체 Readiness 실패로 처리하지 않는 기존 원칙을 유지합니다.

## 업그레이드 전 확인

- PostgreSQL을 백업합니다.
- 기존 `relio-data` Volume이 `/var/lib/relio`에 연결되어 있는지 확인합니다.
- 새 Image로 교체한 뒤 `/health/ready`와 관리자 `Diagnostics · Job` 화면을 확인합니다.
- 운영 URL이 아직 `localhost`라면 관리자 → 시스템 기본정보에서 실제 Service URL로 변경합니다.
