## Relio v1.15.2 — 관리자 탐색과 설정 저장 UX 개선

v1.15.1의 공통 목록 개선을 관리자 콘솔로 확장했습니다. 관리 메뉴 탐색, 설정 저장 결과, 조회 전용 권한과 모바일 편집 흐름을 정리하고 실제 브라우저에서 발견한 연속 저장 방해 문제를 수정했습니다.

## 관리 메뉴와 목록

- 운영 현황판에 **19개 관리 메뉴**를 설명과 함께 제공하는 검색·분류 목록을 추가했습니다. 사이드바와 동일한 메뉴 정보를 사용하며, 여러 단어·대소문자·전각 문자 검색을 지원합니다.
- 현재 메뉴의 분류와 위치를 표시하고 검색 결과 수·초기화·빈 결과 안내를 제공합니다. 현재 메뉴를 보조 기술에 알리고 Ctrl/Cmd 클릭으로 링크를 새 탭에 여는 동작도 유지합니다.
- 백그라운드 작업, 승인 정책, 관리자 연동 키, 방문자 분석 공급자, 메일 발송 기록의 **5개 추가 목록**에 검색·정렬·페이지 이동·행 간격·고정 머리글을 적용했습니다. 날짜와 우선순위는 실제 값으로 정렬하고 발송 시각은 초까지 표시합니다.
- 정렬과 페이지 이동은 **불러온 데이터 범위**에서 동작합니다. 메일 기록은 기존 50건 조회 상한을 표시하며 서버 검색·권한·조회 범위를 변경하지 않습니다.
- 권한 목록은 이름·코드·기능과 데이터 범위로 찾을 수 있습니다. 기능 코드 목록은 필요할 때 펼치고, 권한 편집에서는 기능 검색과 ‘선택한 권한만 보기’를 제공합니다. 검색을 바꿔도 선택한 권한은 유지합니다.

## 안전한 설정 편집

- 시스템 기본정보, SSO 연결, 보안, 관계 분석, 영업 분석 정책, API/MCP 정책, 메일 설정에 공통 편집 흐름을 적용했습니다. 미저장 변경 표시, 저장 중 입력·중복 요청 차단, 최신 값 다시 불러오기, 메뉴·빠른 이동 및 브라우저 새로고침·닫기 시 변경 유실 경고를 제공합니다.
- 설정 조회가 실패하면 기본값으로 대체하지 않고 오류와 재시도를 표시합니다. 사용자·권한·파이프라인·승인·사용자 정의 항목·상품·업무 영역 등의 조회 실패도 무한 로딩 대신 복구할 수 있습니다.
- 기존 설정은 불러온 버전을 함께 전송해 다른 관리자의 변경을 덮어쓰지 않습니다. 동일한 값은 재저장하지 않고 Secret·재시작 필요 여부·값 타입을 보존합니다.
- 설정 API는 항목별 저장 방식입니다. 여러 항목 중 일부만 저장되면 모든 요청이 끝난 뒤 성공·실패 개수와 실패 항목을 표시합니다. 입력을 보존하고 추가 저장을 막으며, 최신 값을 다시 확인하도록 안내합니다. 일괄 트랜잭션 성공으로 표시하지 않습니다.
- 메일 저장 후 입력란이 이전 값으로 되돌아가던 흐름을 수정했습니다. 저장한 Secret 입력은 비우고, 빈 Secret은 기존 값을 유지합니다. 미저장 변경이 있으면 저장된 설정으로 시험 발송·SSO 연결 검사를 실행하지 않도록 안내합니다.
- SSO 연결과 권한·그룹 매핑의 저장 영역을 분리했습니다. 매핑 조회 실패 시 빈 매핑을 저장하지 못하게 하고 입력의 접근성 이름을 추가했습니다.
- 조회 전용 관리자에게 권한 안내를 제공하고 주요 설정 입력과 사용자·조직·권한·파이프라인·승인·업무 영역 등의 변경 진입점을 비활성화했습니다. 상품·방문자 분석의 별도 쓰기 권한과 서버의 기존 권한 검사는 유지합니다.
- 감사 로그와 메일 발송 필터는 늦게 도착한 과거 응답이 최신 조회 결과를 덮어쓰지 않습니다.

## 화면과 상호작용 수정

- **저장 완료 알림이 저장 버튼을 덮어 다음 클릭을 가로채던 문제**를 수정했습니다. 알림을 상단으로 옮기고 클릭을 통과시키며, 성공·오류 결과를 보조 기술에도 알립니다.
- 모바일 영업 실행 정책은 단계 선택과 편집을 세로로 배치하고 건강도 규칙을 카드형으로 표시합니다. 좁은 열에 설명과 입력이 한 글자씩 눌리던 현상을 해소했습니다.
- 운영 진단의 긴 환경변수·키 정보 줄바꿈, 상태 배지 너비, 설정 설명·버튼 간격, 모바일 저장 버튼과 숨은 사이드바 그림자를 정리했습니다.

## 검증

- Go 전체 Test·Vet, TypeScript Typecheck, 프런트엔드 **66개 테스트**, Production Build, npm audit, 환경변수·외부 정적 자산 계약 검사
- 실제 Chrome의 관리자 19개 경로를 데스크톱 1440px·모바일 390px에서 확인하고 가로 넘침·로딩 완료·브라우저 오류·화면 캡처 검사
- 메뉴 검색, 승인 우선순위 숫자 정렬, 실제 연동 키·방문자 분석 목록 검색, 조회 실패 후 재시도, 중복 제출, 동시 수정 충돌, 변경 유실 경고, 연속 저장, 저장 후 API 재조회
- SMTP Secret 빈 입력 보존, SSO Secret 보존, 권한 검색 중 선택 유지, 실제 조회 전용 계정의 UI 비활성화와 직접 설정 쓰기 API 거부
- 격리 환경의 기존 CRM·민원·MCP 회귀 검사와 SSO Secret·Personal Key의 컨테이너·볼륨 교체 연속성 검사
- 이전 공개 릴리스 **v1.15.1 → v1.15.2** 업그레이드 검사

재현용 브라우저 검사는 `scripts/guide/admin-regression.mjs`에 포함했습니다. `RELIO_GUIDE_DISPOSABLE=1`로 지정한 폐기 가능한 환경에서만 실행하며 테스트 계정·권한·승인 정책·연동 키·비활성 분석 공급자를 생성합니다. 운영 환경에 실행하지 마세요.

## 업그레이드

추가 DB 마이그레이션은 없습니다. 기존 업무 영역·부서 코드·민원 필드·권한·키·영업 데이터는 유지하며 미확정 업무 설정값을 임의로 생성하지 않습니다. 기존 릴리스와 동일하게 단일 오프라인 Docker 이미지 압축 파일을 제공합니다. 릴리스 발행과 운영 서버의 실제 이미지 교체는 별도 작업입니다.
