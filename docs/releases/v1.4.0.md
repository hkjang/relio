## Relio v1.4.0 — Data Quality & Configuration Portability

Relio v1.4.0은 CRM 데이터를 단순히 저장하는 수준에서 벗어나 **영업 판단에 사용할 수 있는 데이터 신뢰도**를 관리하고, 에어갭 환경 사이의 관리자 정책을 안전하게 이관하는 Release입니다. v1.3의 운영 Command Center와 Diagnostics를 확장해 데이터 문제를 발견·조치하고 개발·검증·운영 설정을 Diff 기반으로 배포할 수 있습니다.

## 주요 변경 사항

### Data Quality Center

- 고객, 담당자, 진행 Opportunity를 대상으로 0~100 Data Quality Score를 계산합니다.
- 사업자번호 누락, 담당자 없는 고객, 90일 이상 미접촉 고객과 중복 가능 고객을 탐지합니다.
- 연락수단 없는 담당자를 찾아 고객 관계 데이터의 실행 가능성을 점검합니다.
- Next Action 누락, Decision Maker 미확인, 30일 이상 정체된 Opportunity를 식별합니다.
- 각 규칙에 문제 건수, 전체 대상, 완성도, Severity, 가중치와 권장 조치를 제공합니다.
- 최대 8개의 대표 표본에서 Customer 360, Opportunity 또는 Deal Intelligence로 바로 이동합니다.
- 데이터가 없는 영역은 Score를 감점하지 않아 신규 설치 환경을 왜곡하지 않습니다.

### 안전한 Configuration Bundle

- 관리자 설정을 `relio-config/v1` JSON Bundle로 Export합니다.
- 비밀값이 아닌 System Setting, Custom Role/Permission, Pipeline/Stage, Custom Field, Deal Health Rule, 승인 정책, Sales Playbook과 Exit Criteria를 포함합니다.
- 사용자, 조직 Identity, 고객, 담당자, Opportunity 등 업무 데이터는 Bundle에 포함하지 않습니다.
- Password, Secret, Token, Credential, Private/Master Key와 PostgreSQL DSN 계열 설정을 이름과 Secret Metadata로 이중 차단합니다.
- OIDC Provider Credential과 Personal API/MCP Key는 내보내지 않습니다.
- Import는 최대 2MB, Relio Format, 허용 Field Type, Role/Data Scope, Pipeline 확률, 중복 논리 Key와 Sales Execution Enum을 검증합니다.
- `SYSTEM_ADMIN` 같은 시스템 Role은 Bundle로 생성하거나 변경할 수 없습니다.

### Diff Preview와 비파괴 적용

- 적용 전 Section별 `CREATE`, `UPDATE`, `UNCHANGED` 수를 표시합니다.
- 변경 항목을 선택하면 현재 값과 Bundle 적용 후 JSON을 나란히 비교할 수 있습니다.
- 관리자가 안전 범위를 확인하고 명시적 Checkbox를 선택해야 Apply가 활성화됩니다.
- Import는 항목을 삭제하지 않고 논리 Key 기준으로 생성 또는 갱신합니다.
- PostgreSQL Transaction 안에서 전체 Bundle을 적용하므로 중간 실패 시 모두 Rollback합니다.
- 동일한 Setting과 Deal Health Rule은 Version이나 갱신 시각을 불필요하게 변경하지 않습니다.
- Playbook Item과 Exit Criteria는 기존 ID와 Opportunity 완료 이력을 보존하도록 비파괴 Upsert합니다.

### 관리자 UI/UX

- 기존 동작하지 않던 Import/Export 안내 화면을 실제 Data Quality·Configuration Workspace로 교체했습니다.
- Desktop에서는 8개 품질 Rule을 한눈에 비교하고, Tablet과 Mobile에서는 2열·1열로 자연스럽게 재배치합니다.
- 파일 선택 → Diff 검토 → 트랜잭션 적용의 3단계 상태를 명확히 표시합니다.
- `admin:read` 사용자는 Export와 Diff Preview를 사용할 수 있고 Apply는 Bootstrap Admin 또는 `admin:write` 사용자만 수행할 수 있습니다.
- 관리자 Navigation 명칭과 검색 Keyword를 새 기능에 맞게 정리했습니다.

### API와 Audit

- `GET /api/v1/admin/data-quality`: Score, Entity Count, 8개 품질 Category와 표본을 반환합니다.
- `GET /api/v1/admin/configuration/export`: Secret이 제외된 설정 Bundle을 다운로드합니다.
- `POST /api/v1/admin/configuration/preview`: 현재 설정과 Bundle의 Diff를 검증합니다.
- `POST /api/v1/admin/configuration/apply`: 확인된 Bundle을 단일 Transaction으로 적용합니다.
- Export와 Apply는 `CONFIGURATION_BUNDLE_EXPORT`, `CONFIGURATION_BUNDLE_APPLY` Audit으로 기록합니다.
- 내장 OpenAPI와 오프라인 Smoke Test에 신규 API를 반영했습니다.

## 보안 및 호환성

- Application 환경변수는 기존과 동일하게 `POSTGRES_DSN`, `BOOTSTRAP_ADMIN`, `BOOTSTRAP_ADMIN_PASSWORD` 세 개뿐입니다.
- 런타임 CDN, 외부 Font, Telemetry, Package Download는 없습니다.
- Configuration Bundle은 Secret이나 업무 데이터를 복구·이관하는 Backup 수단이 아닙니다. PostgreSQL과 `relio-data` Volume은 기존 Backup 정책으로 함께 보호해야 합니다.
- Database Schema 변경이 없어 v1.3.0 Database와 Volume을 그대로 사용하며 Image 교체만으로 업그레이드할 수 있습니다.
- Bootstrap Admin, Keycloak OIDC, 승인 Workflow, Personal Key Rotation, REST/MCP Permission과 Data Scope 정책은 기존과 호환됩니다.

- 기존 환경 설정을 다른 환경으로 이동할 때는 먼저 Target 환경에서 Diff를 검토하고 적용합니다.
