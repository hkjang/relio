## Relio v1.11.2 — 눌린 입력창과 붙어 있던 제목

두 가지 간격 문제를 고쳤습니다. 하나는 v1.11.1에서 만든 빠른 이동 창의 결함이고, 다른 하나는 처음부터 화면 전체에 있던 문제입니다.

## 1. 패널 제목과 설명이 붙어 있던 문제

### 보고된 문제

> 팀장 검토 대기, 영업 코칭 글자와 위험 점수가.. 이부분 글자가 여전히 딱 붙어 있는것처럼 보여

### 측정한 사실

17px 제목과 14px 설명 사이 간격이 **4px**였습니다. 제목의 `line-height`도 지정되지 않아 글자 상자가 글줄에 바짝 붙어 있었습니다. 두 줄이 하나의 덩어리로 읽혔습니다.

```
.panel-head p { margin: 4px 0 0 }   /* 17px 제목 바로 아래 14px 설명 */
.panel-head h2 { margin: 0 }        /* line-height 미지정 */
```

### 수정

간격을 7px로 넓히고 제목에 `line-height: 1.35`를 주었습니다. `.panel-head`는 화면 전체가 공유하는 규칙이라 영업 현황, 고객, 관리자 화면의 모든 패널이 함께 정리됩니다. 네 화면의 모든 패널에서 7px을 확인했습니다.

## 2. 빠른 이동 입력창이 눌려 있던 문제

### 보고된 문제

> 빠른이동 입력창 부분이 초기에 뜰때 공간이 좁아 보여

### 원인 — v1.11.0에서 고친 것과 같은 종류

입력창에는 `height: 58px`가 지정되어 있었지만 실제로는 **23px로 렌더링**되고 있었습니다.

빠른 이동 창은 세로 flex이고 가운데 목록만 스크롤합니다. 그런데 입력줄과 하단 안내줄에 `flex-shrink`의 기본값이 남아 있었습니다. 처음 열면 항목이 45개라 목록이 `max-height: 70vh`를 넘고, **넘친 만큼 위아래 줄이 눌렸습니다.**

v1.11.0에서 상세 패널이 잘리던 것과 정확히 같은 원인이 다른 자리에서 재현된 것입니다. 스크롤되는 영역을 가진 flex 컬럼에서는 고정되어야 할 부분에 `flex: none`을 명시해야 합니다.

### 수정

| | 수정 전 | 수정 후 |
| --- | --- | --- |
| 입력줄 높이 | 23px (지정값 58px) | **62px** |
| 하단 안내줄 | 눌림 | **37px** |
| 목록 | `min-height: 0` | `flex: 1 1 auto` 명시 |

입력 글자 크기도 16 → 17px로 키우고 좌우 여백을 넓혔습니다.

목록을 끝까지 스크롤했을 때, 검색으로 목록이 짧아졌을 때 모두 62px을 유지하는 것을 확인했습니다.

## 발견 및 수정한 오류

- 모든 패널에서 제목과 설명이 4px 간격으로 붙어 한 덩어리로 읽히던 문제
- 빠른 이동 입력줄이 목록 길이에 눌려 지정 높이의 40%로 렌더링되던 문제
- 빠른 이동 하단 안내줄이 같은 이유로 눌리던 문제
