## Relio v1.11.1 — 어디로든 한 번에, 그리고 읽히는 화면

v1.11.0에서 들어온 화면의 표시 결함을 고치고, 흩어져 있던 이동 수단을 하나로 합쳤습니다.

## 1. 숫자가 붙어 나오던 문제

### 보고된 문제

> 인텔리전스 센터에 090 070 처럼 숫자가 표기되는 문제가 있어.

### 원인

KPI 카드의 CSS는 `p` · `strong` · `small` 구조를 전제합니다. 새로 만든 카드는 `small` · `b` · `span`을 썼고, `b`와 `span`은 아무 스타일도 받지 못한 인라인 요소라 값과 설명이 한 줄로 이어졌습니다.

```
<b>0</b><span>90점 이상</span>   →   090점 이상
```

기존 KPI 카드와 같은 구조로 되돌렸습니다. 값에는 단위를 붙이고, 아이콘과 색조도 다른 카드와 맞췄습니다.

### 함께 발견한 것

같은 화면의 표에도 두 가지 문제가 있었습니다.

- 위험 제목과 설명이 모두 인라인이라 **한 줄로 이어져** 읽을 수 없었습니다 (`품질관리 시스템 통합 진행이 멈춰 있습니다품질관리 시스템 통합 · 상담 단계에서…`).
- 열 너비가 없어 긴 문장이 나머지를 굶겼고, `심각도`와 `감지` 머리글이 두 줄로 접혔습니다.

제목과 설명을 줄로 분리하고 여섯 열에 너비를 지정했습니다.

## 3. 메뉴와 어울리는 스크롤바

사이드바의 스크롤바가 브라우저 기본값이라, 남색 패널 위에 밝은 회색 띠가 세로로 그어져 있었습니다. 메뉴의 일부이므로 메뉴의 색으로 그리고, 포인터가 올라갈 때만 또렷해집니다.

밝은 쪽 영역(상세 패널, 모달, 칸반, 표)도 같은 방식으로 정리했습니다. 스크롤바가 테두리처럼 보이면 안 되기 때문입니다.

## 4. 영업기회 분석 화면 레이아웃

`팀장 검토 대기`와 `영업 코칭`은 각각 다섯 열짜리 표인데 1.45 : 1 두 칸 그리드에 나란히 놓여 있었습니다. 왼쪽 표의 **권장 행동 열이 패널 밖으로 잘렸고**, 오른쪽 코칭 표는 절반이 빈 채로 남았습니다.

두 패널을 위아래로 쌓아 각자 필요한 폭을 온전히 쓰게 했습니다. 1440px에서 두 패널 모두 1136px, 잘림 0을 확인했습니다.

## 5. 내 추천 행동의 상태 선택 박스

페이지 제목 옆에 놓인 `select`가 아무 스타일도 상속받지 못해 브라우저 기본 모양 그대로였습니다. 높이 38px, 둥근 모서리, 커스텀 화살표, 포커스 링을 갖춘 `heading-select`로 정리했습니다.

## 6. 빠른 이동 — 만들었습니다

### 있던 것

상단 검색 상자는 **영업 화면에서 아무 일도 하지 않았습니다.** 입력을 받지 않았고(`onChange`가 없었습니다), Enter를 누르면 검색어를 붙여 고객 목록으로 보낼 뿐이었습니다. 관리자 화면에서는 사이드바 검색과 기능이 겹쳤습니다.

그동안 `/api/v1/search`는 고객·담당자·영업기회를 이미 반환하고 있었고 **화면에서 아무도 호출하지 않았습니다.**

### 만든 것

`⌘K` / `Ctrl+K`로 어느 화면에서나 열리는 이동 창입니다.

| 대상 | 내용 |
| --- | --- |
| **이동** | 영업 업무 · 개인 · 관리자 메뉴 전체 (권한에 따라 필터) |
| **레코드** | 고객 · 담당자 · 영업기회 (두 글자 이상 입력 시, 200ms 디바운스) |
| **실행** | 고객 등록, 영업기회 생성, 활동 기록, 요청 접수 (권한에 따라 필터) |
| **최근 이동** | 마지막으로 연 곳 5개 |

- 검색어는 **공백으로 나눈 모든 단어가 포함**되면 일치합니다. `고객 위험`으로 `고객 위험 분석`을 찾습니다.
- 각 메뉴에 검색 키워드를 달아 `voc`, `deal`, `rbac`, `단가` 같은 말로도 찾힙니다.
- 키보드만으로 완결됩니다. `↑` `↓` 이동, `↵` 열기, `Esc` 닫기, `Home` / `End`.
- 결과는 출처별로 묶여 표시되고, 선택된 항목은 목록 안에서 자동으로 보이는 위치까지 스크롤됩니다.

메뉴 정의는 `nav.ts` 한 곳으로 옮겼습니다. 사이드바와 이동 창이 같은 목록을 보므로 한쪽에만 메뉴가 추가되는 일이 생기지 않습니다.

## 발견 및 수정한 오류

- KPI 카드의 값과 설명이 한 줄로 이어져 `090점 이상`처럼 보이던 문제
- 위험·신호 표에서 제목과 설명이 이어 붙고 머리글이 두 줄로 접히던 문제
- 영업기회 분석의 표가 패널 밖으로 잘리던 문제
- 페이지 제목 옆 선택 박스가 스타일을 상속받지 못하던 문제
- 사이드바 스크롤바가 메뉴 배색과 충돌하던 문제
- 상단 검색 상자가 영업 화면에서 입력을 받지 않던 문제
- 화면에서 호출되지 않던 `/api/v1/search`
- 팔레트의 24px 아바타에서 한글 두 글자가 줄바꿈되던 문제
