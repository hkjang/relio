## Relio v1.5.0 — Multi-Currency Revenue & Contract Execution

Relio v1.5.0은 Opportunity의 가능 금액을 보는 CRM에서 한 단계 더 나아가, **거래통화 원금과 기준통화 Forecast를 함께 관리하고 계약 금액을 실제 매출 이행 일정으로 연결**하는 Release입니다. v1.4의 데이터 신뢰도와 설정 이관 기반 위에 다중 통화 Pipeline, 계약 활성화, Revenue Schedule, 매출 인식과 Renewal Radar를 추가했습니다.

## 주요 변경 사항

### 재현 가능한 Multi-Currency Forecast

- Opportunity, 견적, 계약과 매출에 ISO 3자리 거래통화와 고정 환율을 기록합니다.
- KRW는 환율 1만 허용하고 외화 거래는 생성 시점의 `1 거래통화 = KRW` 환율을 필수로 고정합니다.
- 거래통화 금액은 원본 그대로 보존하며 기준금액과 기준 가중금액을 PostgreSQL Generated Column으로 계산합니다.
- Dashboard, Customer 360, Pipeline, Forecast, Forecast Snapshot, Coaching, Win/Loss와 승인 조건은 KRW 기준금액으로 일관되게 집계합니다.
- Forecast 응답과 화면에서 통화별 원거래 금액, 환산 기준금액과 Deal 수를 함께 확인합니다.
- Manager Forecast Override 금액은 기존과 같이 기준통화 금액으로 해석합니다.

### Contract Revenue Engine

- 계약을 `DRAFT`로 등록하고 검토 후 명시적으로 `ACTIVE`로 전환합니다.
- 활성화 시 `ONE_TIME`, `MONTHLY`, `QUARTERLY`, `ANNUAL` 정책에 따라 Revenue Schedule을 Transaction 안에서 자동 생성합니다.
- 월말 계약은 1월 31일 → 2월 말 → 3월 31일처럼 각 월의 유효한 마지막 날짜로 안전하게 보정합니다.
- 계약 금액을 센트 단위로 정확히 분할하고 나머지를 앞 일정부터 배분해 전체 일정 합계가 계약 원금과 항상 일치합니다.
- 일정별 `PLANNED`, `DUE`, `RECOGNIZED` 상태와 거래통화·기준금액을 조회합니다.
- 매출 인식 시 Sales Ledger 생성과 Revenue Schedule 상태 변경을 하나의 PostgreSQL Transaction으로 처리합니다.

### Renewal Radar와 실행 UX

- 계약 종료일까지 남은 일수, `EXPIRING`/`EXPIRED` Radar 상태와 자동 갱신 조항을 표시합니다.
- 갱신 진행상태를 `NOT_STARTED`, `PLANNED`, `IN_PROGRESS`, `RENEWED`, `CHURNED`로 관리합니다.
- 갱신 다음 행동과 사전 점검 일수를 계약에 기록합니다.
- 계약 화면에 Active 기준금액, 90일 내 점검 건수와 미인식 매출 일정 KPI를 추가했습니다.
- 계약번호·고객·계약명 검색, 상태 필터와 90일 내 만료 필터가 실제 데이터에 적용됩니다.
- Opportunity 검색, Stage와 Forecast Category 필터도 서버 Query와 연결해 기존 비동작 컨트롤을 제거했습니다.

### Keycloak SSO 첫 화면 복구

- 기본 Role 또는 Claim Mapping이 아직 없는 OIDC 자동 프로비저닝 사용자의 `permissions`가 `null`로 직렬화되던 문제를 수정했습니다.
- 서버는 권한이 없는 사용자의 Permission도 항상 빈 JSON 배열로 반환합니다.
- Web Client도 로그인·세션 복원·비밀번호 변경 후 사용자 응답을 정규화해 구버전 또는 비정상 응답의 `permissions.includes` 렌더링 실패를 방지합니다.
- 권한이 없는 OIDC 사용자는 빈 화면 대신 정상 Shell과 권한별 API 오류 안내를 확인할 수 있습니다.

### API와 Audit

- `GET /api/v1/contracts/{id}`: 다중 통화 계약 상세를 조회합니다.
- `POST /api/v1/contracts/{id}/activate`: 계약을 활성화하고 매출 일정을 생성합니다.
- `GET /api/v1/contracts/{id}/revenue-schedule`: 예정·기한 경과·인식 일정을 조회합니다.
- `POST /api/v1/revenue-schedules/{id}/recognize`: 매출을 인식하고 Sales Ledger에 반영합니다.
- `PUT /api/v1/contracts/{id}/renewal`: 갱신 상태와 다음 행동을 저장합니다.
- `GET /api/v1/forecasts`는 `baseCurrency`와 통화별 `currencies` Breakdown을 반환합니다.
- 계약 활성화, 매출 인식과 갱신 계획 변경은 Audit Log에 기록합니다.
- 내장 OpenAPI와 완전 오프라인 Smoke Test에 신규 API를 반영했습니다.

## 보안 및 호환성

- Application 환경변수는 기존과 동일하게 `POSTGRES_DSN`, `BOOTSTRAP_ADMIN`, `BOOTSTRAP_ADMIN_PASSWORD` 세 개뿐입니다.
- 외부 환율 서비스에 접속하지 않으며 생성 시점 고정 환율로 에어갭 환경에서 Forecast 재현성과 감사 가능성을 보장합니다.
- 계약 활성화와 갱신은 `contract:write`, 매출 인식은 `sales:write` 권한을 각각 검사합니다.
- 모든 계약과 Revenue Schedule 조회는 기존 Function Permission과 Data Scope를 적용합니다.
- v1.4 데이터에는 `KRW`, 환율 1과 기존 금액이 자동 적용되므로 데이터 재입력 없이 업그레이드할 수 있습니다.
- 새 `004_multi_currency_contract_engine.sql` Migration은 기준금액 Generated Column과 Revenue Schedule Table을 Transaction으로 추가합니다.
- Bootstrap Admin, Keycloak OIDC 설정, 승인 Workflow, Personal Key Rotation, REST/MCP 정책은 기존과 호환됩니다.
